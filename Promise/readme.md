# Тема урока: Promise

`Promise` - это встроенный объект в JavaScript, который представляет собой промежуточный результат асинхронной операции. Он позволяет работать с асинхронным кодом более удобно и читабельно, чем использование колбеков.

Вы должны понимать принцип работы самого JS. Дело в том что вы привыкли к работе с потоками через `API` самого `.NET`, то есть CLR или же через операционную систему(я сейчас про Thread, ThreadPool, Task и т.д.).

В JS же все работает немного иначе. Сам по себе JS не может выделить вам какой-то поток, он работает в одном потоке. Да тут в целом нет потоков потому что браузер выделяет на ваш tab отдельный поток.

Тут в чат входит реактивное программирование. То есть вы можете подписаться на событие и когда оно произойдет, то вы получите результат.

## Как работает JS под капотом ?

`JS` работает на основе `Event Loop`. Это означает, что он выполняет код в одном потоке и использует очередь событий для обработки асинхронных операций. То есть давайте подумаем логичнески. У нас есть один поток, который выполняет код. Наша задача - это реализовать рработу кода без остановки. В таком случае мы можем делить код на части и выполнять его по очереди. А что если в чат входит I/O операции ?

По идее если пользователь нажал на кнопку на сайте в момент выполнения кода, то мы должны остановить выполнение кода и дождаться результата. Но это не совсем правильно. Мы можем просто отложить выполнение кода до тех пор пока не получим результат.
