# SignalR Integration Guide

## 🎯 Обзор

Этот фронтенд интегрирован с SignalR бэкендом для получения уведомлений в реальном времени.

## 🔧 Архитектура бэкенда

### Endpoints

- **SignalR Hub**: `/hubs/notification`
- **API Endpoint для отправки уведомлений**: `POST /api/v1/Test/Notification`

### Аутентификация

Бэкенд использует JWT аутентификацию с передачей токена через query string:

```
ws://localhost:5056/hubs/notification?access_token=YOUR_JWT_TOKEN
```

### SignalR Events

Бэкенд отправляет уведомления через метод:
- **`ReceiveNotification`** - основной метод для получения уведомлений от бэкенда

## 💻 Фронтенд

### Структура проекта

```
src/
├── hooks/
│   └── useSignalR.ts          # Hook для управления SignalR соединением
├── components/
│   └── NotificationButton.tsx  # Компонент UI для тестирования уведомлений
├── httpclient/
│   └── apiClient.ts           # HTTP клиент для API запросов
└── App.tsx                     # Главный компонент приложения
```

### Как это работает

1. **Подключение к SignalR Hub**
   - При запуске приложения автоматически устанавливается соединение с SignalR Hub
   - Токен передается через query string параметр `access_token`
   - Соединение настроено на автоматическое переподключение

2. **Получение уведомлений**
   - Слушается событие `ReceiveNotification` от бэкенда
   - При получении уведомления:
     - Отображается toast уведомление
     - Проигрывается звуковой сигнал
     - Уведомление добавляется в список

3. **Отправка уведомлений**
   - Пользователь вводит JWT токен в поле
   - При нажатии кнопки "Create Notification":
     - Токен сохраняется в localStorage
     - Происходит переподключение с новым токеном
     - Отправляется POST запрос на `/api/v1/Test/Notification`
     - Бэкенд отправляет уведомление текущему пользователю через SignalR

## 🚀 Запуск приложения

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
VITE_API_URL=http://localhost:5056
```

### 3. Запуск dev сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5175`

## 🔑 Получение JWT токена

Для тестирования вам нужен валидный JWT токен от бэкенда. 

1. Зарегистрируйтесь или войдите через Auth API
2. Скопируйте полученный `accessToken`
3. Вставьте токен в поле "Access Token" на фронтенде

## 🧪 Тестирование

### UI тесты

1. **Test UI** - тестирует только UI компонент без реального SignalR соединения
2. **Debug** - выводит информацию о текущем состоянии:
   - Статус подключения
   - ID соединения
   - Количество уведомлений
   - Наличие токена

### Полный тест

1. Вставьте JWT токен в поле
2. Нажмите "Create Notification"
3. Должно появиться уведомление с текстом "This is a test notification."

## 📝 Основные особенности

### useSignalR Hook

```typescript
const {
  connection,        // SignalR соединение
  isConnected,       // Статус подключения
  setupNotificationListener,  // Установка слушателя уведомлений
  reconnectWithNewToken       // Переподключение с новым токеном
} = useSignalR();
```

### Ключевые методы

- **`setupNotificationListener(callback)`** - настраивает слушатель для событий `ReceiveNotification`
- **`reconnectWithNewToken()`** - переподключается к SignalR с обновленным токеном из localStorage
- **`playNotificationSound()`** - проигрывает звук уведомления

## 🔒 Безопасность

- JWT токен передается через query string для WebSocket соединений (стандартный подход для SignalR)
- Токен также отправляется в Authorization header для HTTP запросов
- Токен хранится в localStorage (для production рассмотрите более безопасные варианты)

## 🐛 Отладка

### Проблемы с подключением

1. Убедитесь, что бэкенд запущен на правильном порту
2. Проверьте CORS настройки на бэкенде
3. Откройте DevTools Console для просмотра логов SignalR

### Уведомления не приходят

1. Убедитесь, что соединение установлено (зеленый индикатор)
2. Проверьте, что токен валидный
3. Убедитесь, что бэкенд отправляет уведомления через метод `ReceiveNotification`

### Полезные логи

Все операции логируются в консоль с эмодзи префиксами:
- ✅ - успешные операции
- ❌ - ошибки
- 🔄 - переподключение
- 🔔 - получение уведомлений
- 🔌 - отключение
- 🔑 - операции с токеном
