# SignalR Notifications Test

Этот проект представляет собой тестовое приложение для демонстрации работы с SignalR уведомлениями.

## Технологии

- **Vite** - сборщик проекта
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **Radix UI** - UI компоненты
- **Microsoft SignalR** - real-time коммуникация
- **Lucide React** - иконки

## Функциональность

- ✅ Подключение к SignalR хабу `hubs/notification`
- ✅ Кнопка для создания уведомления (POST запрос на `/api/v1/Test`)
- ✅ Отображение статуса подключения
- ✅ Звуковые уведомления при получении сообщений
- ✅ Вывод уведомлений в console.log
- ✅ Современный UI с использованием Radix UI и Tailwind CSS

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите проект в режиме разработки:

```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`

## Настройка

URL API настраивается в файле `.env`:

```
VITE_API_URL=http://localhost:5056
```

## Структура проекта

```
src/
├── components/
│   └── NotificationButton.tsx  # Главный компонент с кнопкой и уведомлениями
├── hooks/
│   └── useSignalR.ts          # Хук для работы с SignalR
├── httpclient/
│   └── apiClient.ts           # HTTP клиент для API запросов
├── App.tsx                    # Главный компонент
└── App.css                    # Стили
```

## API Endpoints

- **POST** `/api/v1/Test` - создание тестового уведомления
- **SignalR Hub** `/hubs/notification` - подключение к хабу уведомлений

## Особенности

- Автоматическое переподключение при потере соединения
- Звуковые уведомления с помощью Web Audio API
- Toast уведомления с использованием Radix UI
- Адаптивный дизайн
- Индикатор статуса подключения
