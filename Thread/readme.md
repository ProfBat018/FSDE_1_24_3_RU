## Что такое многопоточность ?

`Многопоточность` - это способность программы выполнять несколько потоков одновременно. Конечно же вы должны понимать, что параллелизма не существует и потоки либо выполняются почти одновременно, либо по очереди.

## Общие сведения о потоках

`Поток` - это обещание выполнить какую-либо задачу. Чтобы создать поток мы используем класс `Thread` из пространства имен `System.Threading`.

Он принимает два делегата, подробнее об этом мы проходили на прошлом уроке. Пример в файле `SystemIntro`

#### Приостановка, возобновление, прекращение потока

Для приостановки потока используется метод `Thread.Sleep(1000);` где 1000 - это время в миллисекундах.

Также у нас есть метод `Thread.Delay(1000);` который делает тоже самое, но в отличии от `Thread.Sleep` он не блокирует поток.


Для прекращения потока используется метод `Thread.Abort();`

`Join` - метод который ожидает завершения потока. 


#### I/O и CPU-bound потоки

`I/O-bound` - это поток который работает с вводом/выводом. Например, чтение файла, запись в файл, чтение из сети и т.д.

`CPU-bound` - это поток который работает с процессором. Например, вычисления, сортировка и т.д.

Когда мы работаем с потоками и нам выходит результат в консоль, то он не отражает реальное время выполнения нашего потока, так как  выводом в консоль занимается другой поток. Тоже самое касается и ввода в консоль.
 

#### Синхронизация потоков
- Monitor
- lock
- Mutex
- Semaphore


`Monitor` - это класс, для синхронизации потоков. Синхронизация потоков - это процесс, который позволяет потокам работать с общими ресурсами без возникновения конфликтов. А так же он не позволяет другим потокам работать с общими ресурсами, пока один поток не закончит работу с ними. 

Для его работы мы создаем пустой объект и передаем его в метод `Monitor.Enter(obj);` и `Monitor.Exit(obj);` 

И конечно же мы делаем его в блоке `try finally` чтобы гарантировать что, поток освободится даже если произойдет исключение.
