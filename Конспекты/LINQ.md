# Тема урока: LINQ

`LINQ` - это Language Integrated Query. По сути это язык внутри языка. Если дословно перевести `LINQ`, то получается "Язык интегрированных запросов". Это набор методов расширений, которые позволяют писать запросы к коллекциям объектов, базам данных и другим источникам данных.

Давайте подробнее поговорим про методы расширения.

```csharp
string name = "Elvin";

name.SayAloha(); // StringExtension.SayAloha(name);

static class StringExtension
{
    public static void SayAloha(this string str)
    {
        Console.WriteLine("Aloha");
    }
}
```

В данном примере мы создали метод расширения `SayAloha`, который принимает строку и выводит на консоль "Aloha". Метод расширения всегда должен быть статическим и находиться в статическом классе. Первым параметром метода расширения должно быть ключевое слово `this`, после которого указывается тип, к которому мы хотим применить метод расширения.
