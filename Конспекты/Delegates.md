# Тема урока: Делегаты

- Что такое делегаты
- Зачем нужны делегаты

`Делегаты` - это указатели на функции, которые вы знаете
еще со времен С++. И так есть несколько важных функций делегатов которые незаменимы в разработке.

Во-первых, делегаты позволяют передавать методы как параметры другим методам. Такой подход мы можем назвать своего рода выполнением принципа `OCP` (Open-Closed Principle) - открытости-закрытости. Также я могу назвать это своего рода инкапсуляцией кода. Такой пример я вам уже показал в [Lesson13](https://github.com/ProfBat018/FSDE_1_24_3_RU/blob/csharp/Lesson13/readme.md)

Во-вторых, в том же примере вы можете увидеть как я реализовал паттерн `Chain of Responsibility` с помощью делегатов и по цепочке вызывал методы.

В-третьих, делегаты позволяют создавать анонимные функции, которые могут быть использованы в качестве параметров методов. Анонимными функциями мы будеи пользоваться 24/7.

## Встроенные делегаты

- Action
- Func
- Predicate

`Action` - это делегат, который не возвращает значение. Он принимает от 1 до 16 параметров и возвращает void. Все его параметры в Generic являются `in` параметрами.

`Func` - это делегат, который возвращает значение. Он принимает от 0 до 16 параметров и возвращает значение. Последний параметр в Generic является `out` параметром.

`Predicate` - это делегат, который возвращает значение типа `bool`. Он принимает один параметр и возвращает значение типа `bool`.

### Вопрос для размышления

Зачем мне Predicate, если я могу использовать Func ?

```csharp

Func<int, bool> func = (x) => x > 5;
Predicate<int> predicate = (x) => x > 5;


var res1 = func(6);
var res2 = predicate(6);

```

Как видите, они одинаковые. Так зачем нам Predicate ?

## Анонимные функции

Анонимные функции - это функции, которые не имеют имени. Они могут быть использованы в качестве параметров методов. Чаще всего такие функции используются в LINQ и похожих запросах.
