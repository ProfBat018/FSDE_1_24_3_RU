# Компоненты в React
Компоненты в React - это основные строительные блоки пользовательского интерфейса. Они позволяют разбивать интерфейс на независимые, переиспользуемые части, что упрощает разработку и поддержку приложений.

Компоненты бывают двух типов: 
- **Функциональные компоненты**: Это простые функции, которые принимают `props` (свойства) и возвращают JSX (JavaScript XML). Они не имеют собственного состояния и жизненного цикла, но могут использовать хуки для управления состоянием и побочными эффектами.
- **Классовые компоненты**: Это более сложные компоненты, которые создаются с помощью классов. Они могут иметь собственное состояние и жизненный цикл, что позволяет управлять поведением компонента в зависимости от его состояния и свойств. При этом тут нет хуков

Это два типа компонентов полностью взаимозаменяемы, но функциональные компоненты с хуками являются более современным и предпочтительным способом создания компонентов в React. Они проще в использовании и позволяют писать более чистый и понятный код.

# Как создавать компоненты ?

#### Пример классового компонента:
```javascript
import React, { Component } from 'react';
class MyComponent extends Component {
  render() {
    return <h1>Hello, {this.props.name}!</h1>;
  }
}
export default MyComponent;
```

#### Пример функционального компонента:
```javascript
import React from 'react';
const MyComponent = (props) => {
  return <h1>Hello, {props.name}!</h1>;
};
export default MyComponent;
```

export default - это синтаксис ES, который позволяет экспортировать компонент по умолчанию из файла. Это означает, что при импорте этого компонента в другом файле, вы можете использовать любое имя для него.
```javascript
import React from 'react';
import MyComponent from './MyComponent'; // Импортируем компонент MyComponent
```

Если ваш компонент не является экспортом по умолчанию, вы можете использовать именованный экспорт:
```javascript
import React from 'react';
export const MyComponent = (props) => {
  return <h1>Hello, {props.name}!</h1>;
};
```
```javascript
import React from 'react';
import { MyComponent } from './MyComponent'; // Импортируем именованный экспорт MyComponent
```

Заметьте что в именованном экспорте вы должны использовать фигурные скобки при импорте компонента, а в экспорт по умолчанию - нет.

В каждом файле вы можете экспортировать только один компонент по умолчанию, но вы можете экспортировать несколько именованных компонентов. Это позволяет вам организовывать код и переиспользовать компоненты в разных частях приложения.

# Как использовать компоненты ?

Чтобы использовать компонент в другом месте вашего приложения, вы должны импортировать его в файл, где вы хотите его использовать. Например, если у вас есть компонент `MyComponent`, вы можете импортировать его следующим образом:

```javascript
import MyComponent from './MyComponent';
```

Затем вы можете использовать этот компонент в JSX-коде, как обычный HTML-тег:

```javascript
import React from 'react';
import MyComponent from './MyComponent';
const App = () => {
  return (
    <div>
      <MyComponent name="World" />
    </div>
  );
};

export default App;
```

# Как передавать данные в компоненты ?
В React вы можете передавать данные в компоненты с помощью `props` (свойств). `Props` - это объект, который содержит данные, которые вы хотите передать в компонент. Вы можете передать любые данные в `props`, включая строки, числа, массивы, объекты и даже функции.
```javascript
import React from 'react';
const MyComponent = (props) => {
  return <h1>Hello, {props.name}!</h1>;
};

const App = () => {
  return (
    <div>
      <MyComponent name="World" />
    </div>
  );
};
