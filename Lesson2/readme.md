## DOM 

`DOM` - это Document Object Model, который представляет собой структуру HTML-документа в виде дерева объектов. Каждый элемент HTML-документа становится объектом, который можно изменять с помощью JavaScript. 

Root элементом является `document`, который представляет весь HTML-документ, а внутри него находятся все элементы, такие как `html`, `head`, `body` и т.д. Каждый элемент имеет свои свойства и методы, которые можно использовать для взаимодействия с ним.

## BOM 
`BOM` - это Browser Object Model, который представляет собой интерфейс между JavaScript и браузером. Он позволяет взаимодействовать с браузером, управлять окнами, вкладками, историей и т.д.
BOM предоставляет доступ к объектам, таким как `window`, `navigator`, `location`, `history` и т.д. Эти объекты позволяют управлять браузером и получать информацию о нем.
