# Проектная работа: Консольное приложение "Избранные фильмы"

## 📌 Цель проекта

Создать консольное приложение на C#, реализующее:

- Регистрацию и логин пользователя
- Поиск фильмов (по названию, жанру и т.д.)
- Добавление фильмов в "Избранное"
- Хранение пользователей и избранных фильмов в базе данных
- Отправку HTML-письма на почту пользователя с избранными фильмами в виде PDF-файлов (по 5 фильмов на PDF)

---

## 🛠️ Технологии

- Язык: C# (.NET 6/7)
- База данных: SQLite / PostgreSQL / SQL Server (по выбору)
- ORM: Entity Framework Core
- PDF генерация: [QuestPDF](https://www.questpdf.com/) или [iTextSharp](https://github.com/itext/itext7-dotnet)
- Отправка почты: `System.Net.Mail` или библиотека `MailKit`
- Сериализация: `System.Text.Json` или `Newtonsoft.Json`

---

## 📋 Требования к функционалу

### 1. Аутентификация

- Пользователь может **зарегистрироваться** (уникальный email + пароль)
- Пользователь может **войти** в систему
- Хеширование пароля с использованием `BCrypt`

### 2. Работа с фильмами

- Поиск фильмов через заранее подготовленный **список фильмов** (или подключение к OMDb API)
- Вывод найденных фильмов в консоль
- Возможность **добавить фильм в избранное**

### 3. Избранные фильмы

- Сохранение избранных фильмов в базе данных, связанных с текущим пользователем
- Команда `export` должна:
  - Собрать все избранные фильмы пользователя
  - Сгруппировать по 5 фильмов на один PDF-файл
  - Сформировать HTML-письмо и прикрепить все PDF-файлы
  - Отправить письмо на email пользователя
