# Тема урока: Делегаты

- Зачем нужны делегаты

- Анонимные функции 

`Делегаты` - это указатели на функции, которые вы знаете 
еще со времен С++. И так есть несколько важных функций делегатов которые незаменимы в разработке. 

Во-первых, делегаты позволяют передавать методы как параметры другим методам. Такой подход мы можем назвать своего рода выполнением принципа `OCP` (Open-Closed Principle) - открытости-закрытости. Также я могу назвать это своего рода инкапсуляцией кода. Такой пример я вам уже показал в []()
