# Повторение SQL

`SQL` - Structured query language 

Мы с вами пишем на `T-SQL`. Сам по себе он делиться на 4 части.
Его синтаксис состоит из: 
- DDL
- DML
- DCL
- TCL

## DDL - Data Definition Language

С помощью него мы описываем структуру наших данных. Он отвечает
за создание изменение удаление частей базы данных, но не отвечает 
за работу с данными.

Глоссарий: 
`CUD` - CREATE, UPDATE, DELETE

С ним вы можете: 
- CUD базу
- CUD таблицу
- CUD индекс
- CUD представление
- CUD хранимую процедуру
- CUD триггер
- CUD функцию
- CUD схему

То есть мы описываем, но не работаем с данными.

## DML - Data Manipulation Language

С помощью него мы работаем с данными. Он отвечает за добавление, 
изменение, удаление данных в таблицах.

Глоссарий:
`CRUD` - CREATE, READ, UPDATE, DELETE

С ним вы можете забирать данные из таблиц, добавлять, изменять, удалять. 

В него входят команды:
- SELECT
- INSERT
- UPDATE
- DELETE
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- UNION
- DISTINCT (Забирает данные без повторения)
- TOP (Забирает первые n строк)
