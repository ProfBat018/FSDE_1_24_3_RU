# Зачем нужен этот предмет ?

Этот предмет в основном изучает работу потоков,
параллелизм и конкурентность. Наша цель, использовать
ресурсы процессора и операционной системы для 
повышения производительности наших программ и реализации
многозадачности. 

# Как работает процессор ?

Для того чтобы создавать потоки и работать с ними,
нам сперва нужно понять как работает процессор и как он взаимодействует
с операционной системой. 

Intel - Hyper-Threading Technology
AMD - SMP (Symmetric Multi-Processing)
ARM - Big.Little

у `Intel` есть P (Performance) и E (Efficiency) ядра. `Hyper-Threading` 
работает только на P ядрах.

у `AMD` есть `SMT` (Simultaneous Multi-Threading)
`SMT` работает на всех ядрах.

По факту алгоритмы управляют ядрами так, чтобы они работали 
в режиме разделения задачи на потоки. 


`ARM` - считаются мобильными процессорами и они самые энергоэффективные. 
`Big.Little` - это технология, которая позволяет использовать
разные ядра для разных задач. Соответственно у них разное потребление 
энергии.

# Многозадачность и многопоточность

Многозадачность - это способность выполнять несколько задач одновременно, 
в независимости от того, сколько потоков вы выделили.

Многопоточность - это способность создавать несколько потоков внутри одного приложения.

# Класс Thread и Process

С помощью класса `Process` можно запускать и уничтожать процессы внутри нашей
операционной системы. 

С помощью класса `Thread` можно создавать и просматривать потоки внутри нашего приложения.

Класс `Thread` принимает 5 конструкторов:
- `Thread()`
- `Thread(ThreadStart start)`
- `Thread(ParameterizedThreadStart start)`
- `Thread(ThreadStart start, int maxStackSize)`
- `Thread(ParameterizedThreadStart start, int maxStackSize)`

`ThreadStart` - делегат, который не принимает параметры и не возвращает значение.
Тут можно подумать, а почему он не принимает сразу `Action` ? Во время создания
`ThreadStart` делегата, `Action` еще не существовало.

`ParameterizedThreadStart` - делегат, который принимает параметры и не возвращает значение.
Он принимает `object` в качестве параметра.
