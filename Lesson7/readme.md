# Темы урока: 
- Cookies, localStorage, sessionStorage


Вы должны понимать два основных принципа работы с данными : 
1. Хранить данные на стороне клиента (в браузере)
2. Хранить данные на стороне сервера (в базе данных или в кеше)

И тут можно задать логичный вопрос, когда и что использовать ?

## localStorage
localStorage - это механизм хранения данных в браузере, который позволяет сохранять данные в виде пар "ключ-значение". Данные хранятся в браузере и доступны даже после закрытия вкладки или перезагрузки страницы.

localStorage имеет следующие характеристики:
- Данные хранятся в виде строк.
- Данные сохраняются в браузере и доступны даже после закрытия вкладки или перезагрузки страницы.
- Данные доступны только в пределах одного домена.
- Максимальный размер хранилища - около 5 МБ (зависит от браузера).
- Данные не имеют срока действия и сохраняются до тех пор, пока не будут удалены вручную или программно.

## sessionStorage
sessionStorage - это механизм хранения данных в браузере, который позволяет сохранять данные в виде пар "ключ-значение". Данные хранятся в браузере и доступны только в пределах одной вкладки. При закрытии вкладки данные удаляются.
sessionStorage имеет следующие характеристики:
- Данные хранятся в виде строк.
- Данные доступны только в пределах одной вкладки.
- Данные удаляются при закрытии вкладки.
- Максимальный размер хранилища - около 5 МБ (зависит от браузера).
- Данные не имеют срока действия и сохраняются до тех пор, пока не будут удалены вручную или программно.

## Cookies
Cookies - это небольшие текстовые файлы, которые хранятся на стороне клиента и отправляются на сервер при каждом запросе. Cookies могут использоваться для хранения информации о пользователе, его предпочтениях и других данных.
Cookies имеют следующие характеристики:
- Данные хранятся в виде пар "ключ-значение".
- Данные отправляются на сервер при каждом запросе.
- Максимальный размер одного cookie - 4 КБ.
- Данные имеют срок действия, который можно задать при создании cookie.
- Cookies доступны на стороне сервера и клиента.

Для использования cookies в JavaScript можно использовать следующие методы: 
```javascript
document.cookie.setItem('key', 'value', { expires: 7, path: '/' });

const value = document.cookie.getItem('key');
```
Но если это httpOnly cookie, то вы не сможете получить его на стороне клиента.
