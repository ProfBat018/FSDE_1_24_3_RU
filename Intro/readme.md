# Введение в TypeScript 

TypeScript — это надстройка над JavaScript, которая добавляет статическую типизацию и другие возможности, улучшая разработку и поддержку кода. Он компилируется в чистый JavaScript, что позволяет использовать его в любом окружении, где работает JavaScript. То есть в независимости от типа проекта, будь то веб-приложение, серверное приложение или мобильное приложение, TypeScript может быть использован для улучшения качества кода и повышения его читаемости. Он добавляет вам более понятную ООП (объектно-ориентированную) модель, что позволяет создавать более структурированный и поддерживаемый код. Для C# программистов изучение и написание кода на TypeScript будет более интуитивным, так как многие концепции и синтаксис схожи с C#. 

`TypeScript` - это интерпретируемый язык программирования созданный Microsoft, который является надстройкой над JavaScript. Он был создан в 2012 году и с тех пор стал популярным инструментом для разработки веб-приложений.  

## Как связаны ECMAScript, JavaScript и TypeScript ?

Как я говорил ранее, во время изучении JavaScript. JavaScript является реализацией стандарта ECMAScript. ECMAScript — это спецификация, которая определяет синтаксис и семантику языка программирования. ECMAScript - это язык без I/O (ввод/вывод), без DOM (Document Object Model) и других возможностей, которые предоставляет JavaScript. Он является основой для JavaSctipt и является языком, на котором написан JavaScript. И получается что все функции, которые есть в `JS` описаны спецификацией `ECMAScript`. Соответсвенно, любой язык, который хочет быть совместим с JavaScript, должен поддерживать спецификацию ECMAScript. 

`TypeScript` в свою очередь явялется надстройкой над `JS`, каким является к примеру C++ над C, но конечно же есть различия. TypeScript интерпретируется в JavaScript, что позволяет использовать его в любом окружении, где работает JavaScript. Сразу же можно задать вопрос, ухудшает ли это производительность? Ответ - нет, так как TypeScript компилируется в чистый JavaScript, который выполняется в браузере или на сервере. Можем посмотреть бенчмарки, но учитывая что TypeScript компилируется в JavaScript, то `RunTime` производительность будет такой же как и у JavaScript. А что касается сборки, то она завичит от настроек транслятора и т.д. В целом она очень незначительная. 

## Как установить TypeScript ?
Для установки TypeScript вам нужно установить Node.js, если он еще не установлен. После этого вы можете установить TypeScript глобально с помощью npm (Node Package Manager). Откройте терминал и выполните следующую команду:

```bash 
npm install -g typescript
```

После установки TypeScript вы можете проверить его версию, выполнив команду:

```bash
tsc -v
```

## Процесс компиляции TypeScript в JavaScript
TypeScript компилируется в JavaScript с помощью команды `tsc`. Вы можете создать файл с расширением `.ts`, например `example.ts`, и затем скомпилировать его в JavaScript, выполнив команду:

```bash
tsc example.ts
```

Это создаст файл `example.js`, который содержит скомпилированный JavaScript код. Вы можете запустить этот файл в браузере или на сервере, как обычный JavaScript файл. 

Если вы хотите сделать автоматическую компиляцию при изменении файлов, вы можете использовать флаг `--watch`:

```bash 
tsc example.ts --watch
```

Это позволит TypeScript автоматически компилировать ваш код при каждом сохранении файла. 

Это в случае если вы хотите компилировать один файл. Если же вы хотите компилировать весь проект, то вам нужно создать файл `tsconfig.json`, который будет содержать настройки компиляции. Вы можете создать его с помощью команды:

```bash 
tsc --init
```

Этот файл будет содержать настройки компиляции, такие как целевая версия JavaScript, пути к исходным файлам и другие параметры. После создания файла `tsconfig.json` вы можете скомпилировать весь проект, выполнив команду:

```bash
tsc
```
