## Что такое HTTP ? 
`HTTP` - это hyper text transfer protocol, протокол 7 уровня модкли OSI который является основополжником интрнета в нашем с вами понимании. 
Из названия уже понятно что этот протокод переносит текст. Под капотом он работает на транспортном протоле TCP, но в зависимости от версии http в этом может быть разница. К примеру если речь идет об http версии 1.1, то он работает на уровне открытия stream-а отдельно для запроса и отдельно для ответа. Но на версии http 2.0 уже открывается лишь один канал для всего. Но давайте не будем сразу так сильно углубляться и для начала поймем как он работает.
