## ShadCn 

`ShadCn` - то библиотека готовых компонентов в стиле Flat Ui, который упрощает нашу разработку. С помощью него можно без проблем писать достаточно сложные и красивые UI. 

Инструкция по его загрузке и использованию есть на официальном сайте, также для примера мы будем работать в проекте `movie-app-shadcn`

## axios 

`Axios` - это библиотека для заругзки данных, то есть для http запросов. Мне она нравится больше чем `fetchapi`.

Пример как работать с axios тоже будет в проекте `movie-app-shadcn`



## SWR 

`SWR` - это библиотека для React, которая занимается подгрузкой данных, их кешированием и пагинацией. Очень важно отметить что он сам по себе не умеет делать http запросы и его нужно использовать либо вместе с axios, либо вместе с fetch. Давайте разберем его пример с кешированием и пагинацией данных. Как всегда пример будет в проекте `movie-app-shadcn`

При использованиии даннрй библиотеки вам  нужно будет в отдельном файле наисать fetcher(для http запросов) и отделоьно уже в самом компоненте использовать хук `useSWR`. Напоминаю, что хуки можно использовать только в функциональных компонентах.
