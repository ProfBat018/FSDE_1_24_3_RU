## Хранимые процедуры

`Хранимые процедуры` - это набор инструкций SQL, которые могут быть вызваны одним запросом. 
Хранимые процедуры обычно используются для выполнения определенных функций, 
которые часто используются в приложениях баз данных.

Синтаксис и использование хранимых процедур:

```sql

CREATE PROCEDURE procedure_name
AS
sql_statement
GO

```

Для того чтобы его вызвать используется ключевое слово `EXECUTE` или `EXEC`:

```sql

EXECUTE procedure_name
```

Пример хранимой процедуры будет в `.sql` файле в папке Lesson9
