# Установка TypeScript
TypeScript можно установить с помощью Node.js и npm (Node Package Manager). Если у вас уже установлен Node.js, то вы можете установить TypeScript глобально, выполнив следующую команду в терминале:

```bash
npm install -g typescript
```

После установки TypeScript вы можете проверить его версию, выполнив команду:

```bash
tsc -v
```

# Внедрение TypeScript в HTML&CSS проект
Для внедрения TypeScript в HTML&CSS проект, вам нужно создать файл с расширением `.ts`, например `script.ts`, и подключить его к вашему HTML файлу. Пример будет в этой папке. 

Сперва  

```bash
tsc --init
tsc --watch
```
Это создаст файл `tsconfig.json`, который содержит настройки компилятора TypeScript. Вы можете настроить его в соответствии с вашими потребностями.

# tsconfig.json и опции компилятора

Файл `tsconfig.json` используется для настройки компилятора TypeScript. Он позволяет вам указать различные параметры компиляции, такие как целевая версия JavaScript, пути к исходным файлам и другие опции. 

# Примитивные типы данных в TypeScript 

`TypeScript` - это строго типизированный язык, что означает, что вы можете явно указывать типы данных для переменных, функций и других элементов. Вот основные примитивные типы данных в TypeScript: 
- `number`: для чисел (целых и дробных).
- `string`: для строк.
- `boolean`: для логических значений (true или false).
- `null`: для обозначения отсутствия значения.
- `undefined`: для обозначения неопределенного значения.
- `any`: для обозначения переменной, которая может иметь любой тип.
- `void`: для обозначения функции, которая не возвращает значение.
- `never`: для обозначения функции, которая никогда не возвращает значение (например, функция, которая всегда выбрасывает исключение).

Для объявления переменных с типами данных в TypeScript вы можете использовать следующий синтаксис:

```typescript
let age: number = 30;
let name: string = "John";
```

При этом если вы напишите:

```typescript
const age = 30;
```
то TypeScript автоматически выведет тип переменной `age` как `number`, так как значение 30 является числом и ничего страшного не будет. Но 
в будущем, если вы будете например принимать параметры в функцию, то вам нужно будет явно указать типы данных, чтобы избежать ошибок. 

# Assertion, Type Guards, Union Types, satisfied types, never type

## Assertion
В TypeScript вы можете использовать утверждения типов (type assertions) для указания компилятору, что вы уверены в типе переменной. Это может быть полезно, когда вы знаете больше о типе переменной, чем компилятор. Синтаксис утверждения типов выглядит следующим образом:

```typescript
let someValue: any = "this is a string"; // предположим что мы берем значение из API и не знаем его тип
let strLength: number = (someValue as string).length;
// или
let strLength: number = (<string>someValue).length;
```

Из этого кодв мы можеи сделать вывод, что `type assertion` - это конструкция языка, которая позволяет программисту явно указать компилятору, что переменная имеет определенный тип, даже если компилятор не может это определить автоматически. Это может быть полезно в ситуациях, когда вы уверены в типе переменной, но компилятор не может это понять.

## Type Guards
Type Guards - это конструкции, которые позволяют вам проверять тип переменной во время выполнения. Это может быть полезно, когда вы работаете с переменными, которые могут иметь разные типы. Например:

```typescript

function printLength(value: string | number) {
    if (typeof value === "string") {
        console.log(`String length: ${value.length}`);
    } else if (typeof value === "number") {
        console.log(`Number value: ${value}`);
    }
}
printLength("Hello, TypeScript!"); // String length: 17
printLength(42); // Number value: 42
```
В этом примере мы используем `typeof` для проверки типа переменной `value`. Если это строка, мы выводим ее длину, если это число, мы выводим его значение.

## Union Types
Union Types позволяют вам объявлять переменные, которые могут иметь несколько типов. Это может быть полезно, когда вы хотите, чтобы переменная могла принимать значения разных типов. Например:

```typescript
function printValue(value: string | number) {
    console.log(`Value: ${value}`);
}

printValue("Hello, TypeScript!"); // Value: Hello, TypeScript!
printValue(42); // Value: 42
``` 

В этом примере функция `printValue` принимает параметр `value`, который может быть либо строкой, либо числом. Это позволяет вам использовать одну функцию для работы с разными типами данных.

## Satisfied Types
Satisfied Types (или "согласованные типы") - это типы, которые соответствуют определенным условиям или интерфейсам. В TypeScript вы можете использовать интерфейсы и классы для определения согласованных типов. Например:

```typescript
interface User {
    name: string;
    age: number;
}

function greet(user: User) {
    console.log(`Hello, ${user.name}! You are ${user.age} years old.`);
}

const user: User = {
    name: "Alice",
    age: 30
};

greet(user); // Hello, Alice! You are 30 years old.
```

В этом примере мы определяем интерфейс `User`, который описывает структуру объекта пользователя. Функция `greet` принимает параметр типа `User`, что позволяет нам гарантировать, что объект, переданный в функцию, соответствует этому интерфейсу.

Интерфейсы в данном языке работают не как в C#. По сути это контракт для объекта, который должен быть реализован. Если объект не соответствует интерфейсу, то TypeScript выдаст ошибку компиляции. А в C# это контракт для класса или структуры. 

## Never Type
Never Type - это специальный тип в TypeScript, который используется для обозначения значений, которые никогда не могут произойти. Например, это может быть полезно для функций, которые всегда выбрасывают исключение или никогда не возвращают значение. Вот пример:

```typescript
function throwError(message: string): never {
    throw new Error(message);
}

function infiniteLoop(): never {
    while (true) {
        // бесконечный цикл
    }
}
```

Такой подход может быть полезен если вы пишите `Global Error Handler` для вашего приложения, который будет перехватывать все ошибки и выводить их в консоль, как это делается в `Global Exception Middleware` в ASP.NET Core. То есть если увас есть функция в которую с точностью на 100% будет передална ошибка, то вы можете использовать `never type`, чтобы указать, что функция никогда не вернет значение.
