## Что такое сетевое программирование ? 

`Сетевое программирование` - это раздел программирования, который отвечает за разработку приложений которые работают по сети. Сейчас можно сказать что почти все приложения работают по сети, так что этот предмет тоже очень важный. 

## Цели и задачи сетевого программирования 

На данном предмете вы должны понять, научиться, освоить принципы работы сети, протоколов, сокетов, портов и в целом научиться связывать приложения между собой. 

Мы будем делать интересные проекты, как например:
- Чат
- Игры
- Клиент-серверные приложения

## Что такое сеть ? 

`Сеть` - это в первую очередь связь между девайсами. Я не буду говорить как можно связать девайсы между собой, или же какие способы связи существуют. Вы это уже знаете. В контексте этого предмета мы будем работать с локальной беспроводной и проводной сетью.

## Модель OSI 

Или как он еще называется `Модель семи уровней`. Это модель которая описывает как работает сеть. Она делит все процессы на 7 уровней. Каждый уровень отвечает за свою часть работы сети.

### UDP vs TCP/IP

`UDP` - User Datagram Protocol - это протокол передачи данных, который не требует установки соединения. Он работает по принципу "отправил и забыл". Это значит что он не гарантирует доставку пакетов, их порядок или целостность. Для передачи он использует датаграммы, которые весят 64kb. Это значит что вы можете отправить 64kb данных за раз. 

`TCP/IP` - Transmission Control Protocol/Internet Protocol - это протокол передачи данных, который требует установки соединения. Он работает по принципу "отправил и жду ответа". Это значит что он гарантирует доставку пакетов, их порядок и целостность. Для передачи он использует потоки, которые весят 1.5kb. Это значит что вы можете отправить 1.5kb данных за раз.

## Базовые термины
- IP адрес
- MAC адрес
- Протокол
- Порт
- Сокет
- Сервер
- Клиент
- Хост

Не путайте Ip и Ip adress. Ip - это интерфейс, а Ip adress - это адрес девайса в сети. 

MAC адрес - это уникальный адрес девайса в сети. Он используется для идентификации девайса в сети. Его невозможно изменить. Он состоит из 6 байт. Например: 00:0a:95:9d:68:16. 

Протокол - это набор правил по которым работает сеть. Например: HTTP, FTP, SMTP, POP3, IMAP, SSH, Telnet и т.д.

Порт - это номер приложения в сети. Например: 80 - HTTP, 443 - HTTPS, 21 - FTP, 22 - SSH, 23 - Telnet и т.д.
