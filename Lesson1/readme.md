# Урок 1: Введение в React

`React` - это JS библиотека для создания пользовательских интерфейсов. Она позволяет разработчикам создавать **многоразовые компоненты**, которые могут быть использованы для построения сложных интерфейсов. 

React был разработан Facebook и стал популярным благодаря своей простоте и эффективности.

# Почему React - это библиотека, а не фреймворк ?
Для того чтобы это понять, нужно понимать разницу между библиотекой и фреймворком.

`Библиотека` - это набор функций, которые вы можете использовать в своем коде. Вы вызываете функции библиотеки, когда вам это нужно. 

`Framework` - это более сложная структура, которая сковывает вас всеми готовыи решениями внутри себя. К примеру давайте вспомним почему `EF Core` - это фреймворк, а не библиотека. Он навязывает вам определенную структуру проекта, определенные подходы к работе с базой данных и т.д. Хоть он и использует под капотом `ADO.NET`, сам по себе `EF Core` дает вам лишь свои интерфейсы для работы с БД. 

Хоть React и предоставляет вам множество функций для создания пользовательских интерфейсов, он не навязывает вам определенную структуру проекта или подходы к разработке. Вы можете использовать React в своем проекте так, как вам удобно, и комбинировать его с другими библиотеками и фреймворками.


## Angular:
Это полноценный фреймворк, предоставляющий всё необходимое для создания SPA (Single Page Application):

- роутинг (навигация между страницами),
- HTTP-клиент,
- формы,
- DI (внедрение зависимостей),
- инструменты для тестирования,
- сборку и CLI.

## React:
- Это библиотека для построения пользовательских интерфейсов.
- Реагирует на изменения состояния и отображает UI.

Всё остальное — роутинг, глобальное состояние, AJAX-запросы, и т.д. — нужно подключать дополнительно (например, React Router, Redux, Axios и т.д.).

# Основные концепции React

`React` основан на нескольких ключевых концепциях, которые делают его мощным инструментом для создания пользовательских интерфейсов:
1. **Компоненты**: Компоненты - это строительные блоки React-приложений. Каждый компонент представляет собой отдельную часть пользовательского интерфейса, которая может быть переиспользована в разных частях приложения.
2. **JSX**: JSX(JavaScript and XML) -  это синтаксис, который позволяет писать HTML-подобный код внутри JavaScript. Он делает код более читаемым и понятным, позволяя разработчикам легко создавать компоненты и их структуру.
3. **Виртуальный DOM**: React использует виртуальный DOM для оптимизации обновлений пользовательского интерфейса. Когда состояние компонента изменяется, React создает виртуальное представление DOM и сравнивает его с реальным DOM, чтобы минимизировать количество изменений, которые нужно внести в реальный DOM. Тем самым он не переделывает полностью весь DOM, а только те части, которые изменились. Это делает обновления интерфейса более эффективными и быстрыми. Именно такой подход позволяет нам создавать SPA(Single Page Application) приложения, которые не перезагружают страницу при взаимодействии с пользователем.
4. **Shadow DOM**: Это тнхгология, которая работает после сравнения виртуального DOM с реальным. Shadow DOM позволяет изолировать стили и структуру компонентов, предотвращая их влияние на другие части приложения. Это особенно полезно для создания компонентов, которые могут быть переиспользованы в разных контекстах без риска конфликтов стилей или поведения. Он рабаотет следующим образом: React с самого начала создает Shadow DOM для каждого компонента, который вы создаете. Это позволяет изолировать стили и структуру компонентов, предотвращая их влияние на другие части приложения.

# Установка и настройка окружения для разработки на React

Для работы с React вам понадобится установить Node.js и npm (Node Package Manager). Node.js - это среда выполнения JavaScript, которая позволяет запускать JavaScript-код на сервере. npm - это менеджер пакетов для Node.js, который позволяет устанавливать и управлять библиотеками и инструментами для разработки. На самом деле сам package manager тоже может быть другим, но npm является стандартом де-факто для Node.js. Если вам хочется использовать другой package manager, то вы можете использовать `yarn` или `pnpm`, но в этом курсе мы будем использовать npm.

## Создание первого приложения на React

Есть несколько способов создать `React` приложение, в этой части урока мы также рассмотрим принцип работы `npx`.

Зачастую нам приходится скачивать пакет с `npm` и устанавливать их глобально для какой-то цели. Например утилита `create-react-app` позволяет быстро создать новое приложение на React. Если вам не хочется устанавливать его глобально, вы можете использовать `npx`(node package execute) - это инструмент, который позволяет запускать пакеты npm без необходимости их установки глобально. Он автоматически загружает и выполняет пакет, если он не установлен.

Вы могли бы написать в терминале:

```bash
npm install -g create-react-app
create-react-app my-app
cd my-app
npm start
```
Но это не всегда удобно, особенно если вы хотите быстро создать новое приложение без установки пакета глобально. Вместо этого вы можете использовать `npx`:

```bash
npx create-react-app my-app
cd my-app
npm start
```

Тут чисто дело вкуса, какой способ использовать. Но в целом `npx` позволяет вам не загромождать вашу систему глобальными пакетами, которые вы используете только один раз.

1. **Использование Create React App**: Это официальный инструмент для создания React-приложений, который предоставляет готовую конфигурацию и инструменты для разработки. Он позволяет быстро начать разработку без необходимости настраивать сборку и другие инструменты вручную.

   Чтобы создать новое приложение с помощью Create React App, выполните следующие команды в терминале:

   ```bash
   npx create-react-app my-app
   cd my-app
   npm start
   ```

   Здесь `npx` - это команда, которая позволяет запускать пакеты npm без необходимости их установки глобально. Она автоматически загрузит и выполнит пакет `create-react-app`, создавая новое приложение в папке `my-app`.

2. **Использование Vite**: Vite - это современный инструмент для сборки приложений, который обеспечивает быструю разработку и оптимизированную сборку. Он также поддерживает React и позволяет создавать приложения с минимальной конфигурацией.

   Чтобы создать новое приложение с помощью Vite, выполните следующие команды в терминале:

   ```bash
   npm create vite@latest my-app --template react
   cd my-app
   npm install
   npm run dev
   ```

   Здесь `npm create vite@latest` создает новое приложение с использованием шаблона React.

3. **Ручная настройка**: Если вы хотите больше контроля над конфигурацией вашего приложения, вы можете создать React-приложение вручную, установив необходимые зависимости и настроив сборку с помощью Webpack или другого инструмента.

    Для этого вам нужно будет установить React и ReactDOM, а также настроить Babel и Webpack для транспиляции и сборки вашего кода. Этот подход требует больше усилий, но позволяет гибко настраивать приложение под ваши нужды.
    
    Пример установки зависимостей:
    
    ```bash
    npm init -y
    npm install react react-dom
    npm install --save-dev babel-loader @babel/core @babel/preset-env @babel/preset-react webpack webpack-cli
    ```
    
    Затем вам нужно будет создать конфигурационные файлы для Babel и Webpack, а также настроить структуру проекта.

При названии проекта обязательно использовать `kebab-case` (через дефис), так как это является стандартом для именования папок и файлов в JavaScript экосистеме. Например, `my-app`, а не `myApp` или `MyApp`.
