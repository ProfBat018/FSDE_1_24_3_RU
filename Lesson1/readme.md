## Ключевые слова для объявления переменных
- var
- let
- const

var - это устаревшее ключевое слово, которое используется для объявления переменных. Оно позволяет создавать переменные, которые могут быть изменены в дальнейшем. Однако, использование var может привести к проблемам с областью видимости переменной, так как она будет доступна во всей функции, в которой была объявлена. Поэтому рекомендуется использовать let и const вместо var.

let - создает переменные точно так же как и var, но более привычным нам образом как в C#.

const - используется здесь чаще чем в других языках, так как в WEB разработке мы часто используем константы.

```js
/*

    age: 30

var a = 5;

```

## Примитивные типы данных
- string (строка)
- number (int)
- boolean 
- null
- undefined (если переменная не была объявлена или резульат загрузки не был)
- symbol (уникальный идентификатор, который может быть использован в качестве ключа для свойств объектов)
- bigint (long) 
- object (JSON объект)
- array (массив)
- function (функция, да это тоже тип данных)
- date (дата)
- regexp (Regex)
- error (Exception)
- map (Dictionary)
- set (Множество, как в Python)
- weakmap (Тоже что и map, но с более слабой ссылкой на объект)
- weakset (Тоже что и set, но с более слабой ссылкой на объект)
- promise (Task из C#)
