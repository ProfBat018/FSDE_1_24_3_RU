# Домашнее задание: Работа с Entity Framework Core (Code First)

## Описание
Студенты должны создать консольное приложение с использованием **Entity Framework Core** и подхода **Code First**. В качестве базы данных использовать **MS SQL Server**. Необходимо соблюдать принципы **нормализации** базы данных.

## Тема проекта: **"Автосалон"**
В рамках задания необходимо разработать систему для управления автомобилями, клиентами и продажами в автосалоне.

---

## **Требования к выполнению**

1. **Настройка проекта**
    - Создать консольное приложение на C#.
    - Добавить поддержку **Entity Framework Core** и **MS SQL Server**.
    - Настроить строку подключения в `appsettings.json` или через `DbContext`.

2. **Создание моделей**
    - Разработать **минимум 5 сущностей**.
    - Применить **Code First Migrations** для создания базы данных.

3. **Создать следующие таблицы (минимум 5):**
    - `Car` (Автомобиль) - содержит информацию о марке, модели, годе выпуска, цене и т. д.
    - `Customer` (Клиент) - хранит данные о клиентах.
    - `Sale` (Продажа) - фиксирует информацию о продажах автомобилей.
    - `Employee` (Сотрудник) - менеджеры по продажам.
    - `ServiceHistory` (История обслуживания) - записи о техническом обслуживании.

4. **Связи между таблицами**
    - Один клиент может купить несколько автомобилей (**one-to-many**).
    - Один автомобиль может иметь несколько записей об обслуживании (**one-to-many**).
    - Продажа связывает **автомобиль, клиента и сотрудника**.

5. **Нормализация базы данных**
    - Исключить дублирование данных.
    - Использовать отдельные таблицы для сущностей, вместо хранения информации в одной таблице.
    - Добавить **таблицу справочников** (например, для типов автомобилей).

6. **Добавить валидацию данных**
    - Обязательные поля.
    - Ограничения на длину строк.
    - Проверка цен и дат.

7. **Заполнить базу тестовыми данными**
    - Использовать `HasData()` для заполнения таблиц начальными данными.
    - Добавить **минимум 10 клиентов**, **5 автомобилей** и **5 продаж**.

8. **Реализовать CRUD-операции**
    - Добавление, удаление, обновление и получение данных для всех сущностей.
    - Вывод информации в консоль.

9. **Написать LINQ-запросы**
    - Найти все автомобили, купленные конкретным клиентом.
    - Вывести список продаж за определенный период.
    - Подсчитать количество продаж каждого менеджера.
