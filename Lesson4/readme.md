## Объект

В `JS` есть понятие объектов. Вы можете сравнить его с наномиными объктами в C#, которые писались вот так (P.S. вспомните как мы делали проекцию в EF CORE): 
```csharp

var person = new
{
    Name = "John",
    Age = 30,
    Address = new Address
    {
        City = "New York",
        Street = "5th Avenue"
    }
};

var address = context.Addresses.Select(a => new
{
    a.City,
    a.Street
}).ToList();
``` 

При этом в `JS` вы можете создавать полноценные объекты у которых есть методы и свойства. 
```javascript

const person = {
    name: "John",
    age: 30,
    address: {
        city: "New York",
        street: "5th Avenue"
    },
    greet: function() {
        console.log(`Hello, my name is ${this.name}`);
    }
};
``` 

Вы должны привыкнуть к написанию перпеменных с помощью константы. В `JS` объекты не принято создавать с `let` в случае если вы не собираетесь менять ссылку на объект. УТОЧНЯЮ !!! ИМЕННО ССЫЛКУ, А НЕ САМ ОБЪЕКТ. 

То есть мы можем сделать вот так: 

```javascript

const person = {
    name: "John",
    age: 30
};

person.name = "Mike"; // Изменяем свойство объекта

console.log(person.name); // Mike

```

но не можем сделать вот так: 

```javascript
const person = {
    name: "John",
    age: 30
};

person = {
    name: "Mike",
    age: 25
}; // Ошибка: Assignment to constant variable.
```

Один из главных моментов это работы ключевого слова `this`. Он не работает так как вы этого ожидаете. 

```javascript
const person = {
    name: "John",
    age: 30,
    greet: function() {
        console.log(`Hello, my name is ${this.name}`);
    }
};

person.greet(); // Hello, my name is John

const person = {
    name: "John",
    age: 30,
    greet: () => {
        console.log(`Hello, my name is ${this.name}`);
    }
};

person.greet(); // Hello, my name is undefined

```

В случае когда вы пишите function рядом с методом, то `this` будет ссылаться на объект в котором он находится. В случае когда вы пишите стрелочную функцию, то `this` будет ссылаться на родительский объект.

Давайте рассмотрим пример: 
```javascript

const user = {
    name: "John",
    greet: function() {
        return `Hello, ${this.name}`;
    },
    greet2: () => {
        return `Hello, ${this.name}`;
    },
    greet3: function() {
        return () => {
            return `Hello, ${this.name}`;
        };
    },
    greet4: () => {
        return () => {
            return `Hello, ${this.name}`;
        };
    },
    greet5: function() {
        return function() {
            return `Hello, ${this.name}`;
        };
    },
};

const user2 = {
    name: "Jane",
    greet: user.greet,
    greet2:user.greet2,
    greet3: user.greet3,
    greet4: user.greet4,
    greet5: user.greet5,
};

console.log(user.greet()); // Hello, John
console.log(user2.greet()); // Hello, Jane

console.log(user.greet2()); // Hello, undefined
console.log(user2.greet2()); // Hello, undefined

console.log(user.greet3()()); // Hello, John
console.log(user2.greet3()()); // Hello, Jane

console.log(user.greet4()()); // Hello, undefined
console.log(user2.greet4()()); // Hello, undefined

console.log(user.greet5()()); // Hello, undefined
console.log(user2.greet5()()); // Hello, undefined

```

## Массивы 

Массивы в `JS` это объекты. Они могут содержать в себе любые типы данных. 
```javascript
const array = [1, 2, 3, "string", true, null, undefined, {}, []];

console.log(array[0]); // 1
console.log(array[3]); // string
console.log(array[4]); // true


```
