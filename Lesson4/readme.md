## Type inference 

В `TypeScript` типы переменных могут быть определены автоматически на основе присвоенных значений. Это называется "type inference" (выведение типов). Например:

```typescript
let message = "Hello, TypeScript!";
```
В этом случае `TypeScript` автоматически определит, что `message` имеет тип `string`.

Просто во время компиляции `TypeScript` проверит, что присваиваемое значение соответствует ожидаемому типу. Если вы попытаетесь присвоить значение другого типа, TypeScript выдаст ошибку.

```typescript
let message = "Hello, TypeScript!";
message = 42; // Ошибка: Type 'number' is not assignable to type 'string'.
```

чтобы у него было такое поведение, нужно явно указать any
```typescript
let message: any = "Hello, TypeScript!";
message = 42; // Теперь это допустимо, так как message имеет тип any.
```

## Type compatibility 
TypeScript использует концепцию "type compatibility" (совместимость типов) для определения того, могут ли два типа быть использованы взаимозаменяемо. Это означает, что если один тип может быть использован в месте, где ожидается другой тип, то они считаются совместимыми.
Например, если у вас есть функция, которая принимает параметр типа `string`, вы можете передать значение типа `string` или значение, которое является подтипом `string` (например, `string | number`), и TypeScript не выдаст ошибку.

```typescript
function greet(name: string) {
    console.log(`Hello, ${name}!`);
}
greet("Alice"); // Допустимо
greet(42); // Ошибка: Argument of type 'number' is not assignable to parameter of type 'string'.
```

Также можно сказать про `bool` и `number`:
```typescript
let isActive: boolean = true;
let count: number = 10;
isActive = count; // Ошибка: Type 'number' is not assignable to type 'boolean'.
count = isActive; // Ошибка: Type 'boolean' is not assignable to type 'number'.
```

## Union types

TypeScript позволяет создавать переменные, которые могут принимать значения нескольких типов, используя "union types" (объединенные типы). Это позволяет более гибко определять типы переменных и параметров функций.
Например, вы можете создать переменную, которая может быть либо `string`, либо `number`:

```typescript
let value: string | number;
value = "Hello"; // Допустимо
```

## Intersection types
TypeScript также поддерживает "intersection types" (пересечение типов), которые позволяют комбинировать несколько типов в один. Это полезно, когда вы хотите создать тип, который должен соответствовать нескольким интерфейсам или классам одновременно.
Например, вы можете создать тип, который должен быть как `A`, так и `B`:

```typescript
interface A {
    a: string;
}
interface B {
    b: number;
}

type C = A & B;

let obj: C = {
    a: "Hello",
    b: 42
}; // Допустимо, так как obj соответствует обоим интерфейсам A и B
```

## Type aliases
TypeScript позволяет создавать псевдонимы типов с помощью ключевого слова `type`. Это позволяет создавать более читаемые и понятные типы, особенно для сложных структур данных.

```typescript
type Point = {
    x: number;
    y: number;
};
type Circle = {
    center: Point;
    radius: number;
};
let circle: Circle = {
    center: { x: 0, y: 0 },
    radius: 5
}; // Допустимо, так как circle соответствует типу Circle
```

## Разница между интерфейсами и типами 

Интерфейсы и типы в TypeScript имеют много общего, но есть и некоторые различия:
1. **Расширяемость**: Интерфейсы могут быть расширены с помощью ключевого слова `implements`, что позволяет создавать новые интерфейсы на основе существующих. Типы не поддерживают это напрямую, но можно использовать пересечение типов (`&`) для достижения аналогичного эффекта.
2. **Объединение**: Интерфейсы могут быть объединены, если они имеют одинаковое имя. TypeScript автоматически объединит их в один интерфейс. Типы не поддерживают объединение, но можно использовать объединенные типы (`|`).
3. **Определение методов**: Интерфейсы могут определять методы, которые должны быть реализованы классами, реализующими этот интерфейс. Типы не могут определять методы напрямую, но можно использовать функции в качестве типов.

Если говорить простым языкм, то тип - это всего лишь псевдоним дл нескольких данных. Можно сказать что это стурктура данных с урезанным функционалом. Интерфейс же - это полноценная структура данных, которая может быть расширена и реализована в классах. 

Например, тот пример выше который я вам показал с Circle и Point, можно было бы сделать и с интерфейсами:

```typescript
interface Point {
    x: number;
    y: number;
}
interface Circle {
    center: Point;
    radius: number;
}
let circle: Circle = {
    center: { x: 0, y: 0 },
    radius: 5
}; // Допустимо, так как circle соответствует интерфейсу Circle
```

В целом они могут использоваться взаимозаменяемо, но интерфейсы более гибкие и мощные, особенно когда дело касается расширения и реализации в классах. Соответственно, я всегда использую именно их. Особенно если речь идет о создании каких-то DTO для работы с API или базой данных.


#### Объединение интерфейсов
TypeScript позволяет объединять интерфейсы с одинаковым именем. Это означает, что вы можете определить один и тот же интерфейс несколько раз, и TypeScript автоматически объединит их в один интерфейс. Это полезно для расширения интерфейсов или добавления новых свойств.

```typescript
interface User {
    name: string;
}
interface User {
    age: number;
}
let user: User = {
    name: "Alice",
    age: 30
}; // Допустимо, так как интерфейс User объединен
```
