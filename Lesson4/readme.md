# Что такое FTP ?

`FTP` - это **File transfer protocol** или протокол передачи файлов. Он используется для передачи файлов между клиентом и сервером по сети. FTP позволяет пользователям загружать и скачивать файлы, а также управлять ими на удаленном сервере. Но не думайте что если вы скачиваете `mp3` файл с сайта, то вы используете FTP. 

Пример использования FTP в реальной практике на самом деле немного устарел, так как он в последствии был заменен обычной `HTTP` работой. При этом для нас программистов одним из самых часто используемых примеров являлось передача нашей программы на сервер путем отправки нашего проекта на сервер через FTP. Если вы в `Visual Studio` или `Rider` нажмете правой кнопкой мыши на проекте и выберете `Publish`, то вы увидите, что там есть возможность отправить ваш проект на сервер через FTP. 


# Как работает FTP ?

FTP работает по модели клиент-сервер. Клиент отправляет запросы на сервер, который обрабатывает их и отправляет ответ. FTP использует два канала для передачи данных: один для команд (управляющий канал) и другой для передачи файлов (канал данных). Тут важно понимать, что FTP работает по протоколу `TCP`, который обеспечивает надежную передачу данных. Если говорить по модели `OSI`, то FTP работает на уровне `приложения` и использует порты `20` и `21`. Порт `21` используется для управления соединением, а порт `20` - для передачи данных.

# Разница между FTP и SFTP

`SFTP` - это **Secure File Transfer Protocol** или защищенный протокол передачи файлов. Он обеспечивает безопасную передачу данных по сети, используя шифрование. SFTP работает по протоколу `SSH`, который обеспечивает защиту данных от перехвата и подмены. В отличие от FTP, SFTP использует один канал для передачи данных и управления соединением, что упрощает настройку брандмауэра и повышает безопасность.
