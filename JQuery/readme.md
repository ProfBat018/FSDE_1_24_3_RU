# Тема урока: JQuery 

### Что такое JQuery ?

`JQuery` - это библиотека JavaScript, которая упрощает работу с HTML-документами, обработку событий, анимацию и взаимодействие с сервером. Она позволяет разработчикам писать меньше кода для выполнения сложных задач.

### Зачем нужен JQuery ?

В современном мире веб-сайты уже устарели, но мы с вами его пройдем, так как это не сложная и интересная тема. JQuery позволяет разработчикам легко манипулировать DOM, обрабатывать события и выполнять AJAX-запросы, что делает его популярным инструментом для создания интерактивных веб-приложений.
