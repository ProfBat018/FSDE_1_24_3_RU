## Что такое SignalR ?

`SignalR` - это библиотека для ASP.NET,
которая упрощает процесс добавления функциональности в реальном
времени в веб-приложения.
Она позволяет серверу отправлять обновления клиентам мгновенно, 
без необходимости клиентам постоянно опрашивать сервер на наличие новых данных.
SignalR поддерживает различные транспортные механизмы, 
включая WebSockets, Server-Sent Events и Long Polling, 
автоматически выбирая наиболее подходящий метод в зависимости от возможностей клиента и сервера.

#### Как это работает ?

Для начала вы должны понимать принцип publisher-subscriber (pub/sub). 
То есть наш Back-End будет выступать в роли издателя (publisher), а подписчики (subscribers)
которых может быть много, будут получать от него сообщения. 

Данная технология работает с помощью отельного TCP соединения, который работает независимо 
от вашего основного HTTP соединения.
